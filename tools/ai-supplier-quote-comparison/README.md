# Supplier Quote Comparison

Deterministic quote comparison API that computes an estimated landed-cost total, flags missing/comparability terms, and ranks offers using explicit adjustable weights. It does not award a contract or contact suppliers.

## Run in Alpha

Open the unified workspace from project-alpha with powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1. This tool opens as a workflow inside the Alpha site at http://127.0.0.1:8000.

## Limits

Use only synthetic offers in this demo. Validate quote source and versions, tax/freight/incoterm rules, units, compliance and score policy with a human analyst. Scores are not procurement recommendations without that review.
