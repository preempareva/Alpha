# Runbook

Start the local API and use `/docs` for a comparison. Validation errors indicate incompatible currencies, invalid weights, or malformed fields; correct the source quote instead of guessing missing terms. The API returns `NEEDS_REVIEW` for missing cost/quality/delivery information or absent compliance confirmation. No data is stored and no external action is available. Before real use, provide authenticated access, authorized quote storage, version/audit history, currency conversion source/time, policy approval and data retention.
