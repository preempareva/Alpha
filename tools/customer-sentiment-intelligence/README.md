# Customer Sentiment Intelligence

Synthetic review analytics prototype with a temporal TF-IDF + logistic regression sentiment baseline, majority-class comparison, per-class metrics, and lightweight keyword themes. It is intended to show an evaluation workflow, not to represent actual customer feedback.

## Run in Alpha

Open the unified workspace from project-alpha with powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1. This tool opens as a workflow inside the Alpha site at http://127.0.0.1:8000.

## Limits

Generated text is templated and vocabulary is narrow. Theme tags are hand-authored keywords, not topic modeling. There are no real reviews, consent records, language coverage guarantees, human-label quality checks, or causal claims. Review errors before any product or support decision.
