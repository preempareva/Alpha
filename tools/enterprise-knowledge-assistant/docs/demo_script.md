# Three-minute demo

1. Start from the seeded synthetic corpus and say that all sources are fictional.
2. As Alice, ask “What is the domestic hotel claim limit?” Show the INR 2,500 excerpt, version, heading and indexing time.
3. As Bob, ask the same question. Show safe abstention because he lacks the Finance group.
4. Ask a question absent from the corpus and show abstention.
5. Open ingestion status and explain active source versions and failed-file review status.
6. Close with the benchmark metrics and limits: tiny authored evaluation set, lexical retrieval only, no real enterprise savings or production-security claim.
