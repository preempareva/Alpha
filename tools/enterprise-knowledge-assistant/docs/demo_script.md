# Three-minute demo

1. Start from the seeded synthetic corpus and say that all sources are fictional.
2. Sign in as Alice with the one-time credential printed at server startup; ask “What is the domestic hotel claim limit?” Show the cited source, version, heading and indexing time.
3. Sign in as Bob and ask the same question. Show safe abstention because his server-side account lacks the Finance group.
4. Ask a question absent from the corpus and show abstention.
5. Sign in as Admin, open ingestion status, and explain active source versions and failed-file review status.
6. Close with the benchmark metrics and limits: tiny authored evaluation set, lexical retrieval only, no real enterprise savings or production-security claim.
