# Travel Itinerary Planner

Constraint-based itinerary prototype for a fictional demo city. It ranks a small authored activity catalog against trip days, interests, per-day budget, available hours, and accessibility preference. Every activity links to its fictional catalog row. It does not use live travel sources or book/pay for anything.

## Run in Alpha

Open the unified workspace from project-alpha with powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1. This tool opens as a workflow inside the Alpha site at http://127.0.0.1:8000.

## Limits

Prices, opening times, availability, accessibility details, and destination are illustrative fiction. Do not use for actual travel decisions. Real deployment needs verified source freshness, itinerary feasibility, transit time, cancellation terms, and explicit human confirmation before booking.
